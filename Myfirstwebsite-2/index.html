:hover

Al pasar el cursor, cambia el aspecto.

nav:hover { filter: brightness(1.14); }
Prueba con el mouse o la tecla Tab.

:active

Mientras mantienes presionado el clic.

section:active { outline: 4px solid white; }
Prueba con el mouse o la tecla Tab.

:focus

Elemento que tiene el foco.

section:focus { outline: 4px dashed white; }
Prueba con el mouse o la tecla Tab.

:focus-visible

Foco visible al navegar con teclado.

aside:focus-visible { outline: 4px solid #0af; }
Prueba con el mouse o la tecla Tab.

:focus-within

Contenedor con un hijo enfocado.

section:focus-within { box-shadow: inset 0 0 0 4px #0af; }

:any-link

Cualquier enlace que tenga href.

main a:any-link { text-decoration-thickness: 3px; }
Enlace de prueba

:link

Enlace aún no visitado.

section a:link { color: #174bbb; }
Enlace de prueba

:visited

Enlace visitado (con restricciones de privacidad).

aside a:visited { color: purple; }

:last-child

Uno Dos Tres

:nth-child()

section .muestra > span:nth-child(2) { background: #ffe36a; }
Uno Dos Tres

:nth-last-child()

Cuenta hijos desde el final.

nav .muestra > span:nth-last-child(2) { background: #ffe36a; }
Uno Dos Tres

section .muestra > span:first-of-type { text-decoration: underline; }
Uno Dos Tres

:last-of-type

Último hermano de la misma etiqueta.

nav .muestra > span:last-of-type { text-decoration: underline; }
Uno Dos Tres

:nth-of-type()

Elige el n-ésimo hermano del mismo tipo.

Uno Dos Tres

:nth-last-of-type()

:root

Raíz HTML; útil para variables CSS.

:root { --color-demo: #0a5; }
Variable CSS disponible en toda la página.

:not()

Excluye elementos que cumplen la condición.

Incluido Excluido

:is()

Agrupa selectores y facilita combinarlos.

nav :is(.muestra) { border-bottom: 3px solid; }
Elemento seleccionado

:where()

Agrupa selectores con especificidad cero.

section :where(.muestra) { outline: 2px dotted; }
Elemento seleccionado

:has()

Selecciona un padre según su contenido.

Número fuera de los límites permitidos.
